# 📊 Superstore Sales Dashboard — Excel

## 📌 Project Overview

The **Superstore Sales Dashboard** is an interactive sales analytics dashboard developed using **Microsoft Excel** to transform sales data into meaningful business insights through structured analysis and data visualization.

This project is my **first hands-on Excel dashboard project**, created to build practical experience in data analysis, KPI reporting, Pivot Tables, interactive filtering, and business-oriented dashboard design.

The dashboard provides a consolidated view of sales performance across different time periods, customer segments, regions, product categories, and sub-categories.

---

## 🎯 Project Objective

The main objective of this project was to develop an interactive Excel dashboard that enables users to:

- Monitor overall sales performance
- Track key business KPIs
- Analyze monthly sales trends
- Analyze monthly quantity sold
- Identify the top-performing customer segment
- Identify the top-performing product category
- Compare year-wise sales performance
- Analyze sales across product sub-categories
- Understand segment-wise performance
- Explore regional performance
- Filter and analyze data dynamically
- Present business data through clear and interactive visualizations

## 📂 Workbook Structure

The complete analysis is maintained within a single Excel workbook consisting of:

### Database
Contains the underlying sales dataset used for analysis.

### Pivot Table
Contains summarized and analytical data prepared using Pivot Tables.

### Dashboard
Contains the final interactive dashboard with KPIs, charts, filters, and visual analysis.

The overall workflow follows:

**Raw Data → Pivot Table Analysis → Interactive Dashboard**

## 📈 Dashboard Analysis

### 1. Monthly Sales Analysis

The dashboard provides a month-wise view of sales performance from **January to December**, making it easier to identify variations and trends throughout the year.

### 2. Monthly Quantity Sold

A monthly quantity trend is included to understand the number of units sold across the year.

The displayed monthly quantity values range from **62 units to 629 units**, providing visibility into changes in sales volume over time.

### 3. Customer Segment Analysis

The dashboard analyzes performance across three customer segments:

- Consumer
- Corporate
- Home Office

The dashboard identifies **Consumer** as the Top Segment.

### 4. Category Analysis

The dashboard provides category-level analysis and identifies:

**Top Category: Technology**

### 5. Sub-Category Sales Analysis

The dashboard provides a detailed sales comparison across multiple product sub-categories, including:

- Tables
- Supplies
- Storage
- Phones
- Paper
- Machines
- Labels
- Furnishings
- Fasteners
- Envelopes
- Copiers
- Chairs
- Bookcases
- Binders
- Art
- Appliances
- Accessories

This allows product-level sales performance to be evaluated across different sub-categories.

### 6. Year-wise Sales Analysis

The dashboard provides a year-wise comparison across:

- 2011
- 2012
- 2013
- 2014

This enables users to compare sales performance across different years.

### 7. Segment-wise Visualization

A dedicated visualization provides a comparative view of sales contribution across:

- Consumer
